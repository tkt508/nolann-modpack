# Pourquoi utiliser Nolann's ModPack ?

Nolann's ModPack est un modpack qui à pour but d'améliorer l'expérience de jeu vanilla en boostant les performances de Minecraft et en ajoutant plusieurs fonctionnalités utiles.

### Quels sont les mods / fonctionnalités utiles ?

- **Shulker Box Tooltip** : Voir l'intérieur des shulkers box sans même les poser au sol !
- **AdvancementInfo Reloaded** : Obtenir plus d'information pour la réussite de vos succés !
- **Command Keys** : Executer des commandes avec la simple pression d'une touche !
- **Simple Voice Chat** : Parler en jeu avec vos amis grave au tchat vocal de proximité !
- **Skin Restorer** : Avoir un skin qui peut être changer a tout momment !
- **Zoomify** : Pouvoir zoomer super loin sans utiliser de longue vue !
- **Xaero's Minimap** : Voir toutes les zones que vous avez explorer !
- **uku's Armor HUD** : Savoir lorsque votre amure vas se casser !
- **Health Indicators** : Voir la vie des autres joueurs / créatures !
- **ReplayMod** : Enregistrer vos sessions de jeu et reviver les quand vous voulez !
- **No Peeking!** : Cacher votre mot de passe lors du /login en multijoueur !
- **Gamma Utils (Fullbright)** : Voir correctement sans avoir a poser des torches !

# FAQ !

### En quels versions le ModPack est t'il disponible ?

Le ModPack est actuellement seulement supporté en 1.21.8.

### Où puis-je signaler les bug du ModPack ?

Il n'est pas encore possible de signaler des bugs à l'équipe.

### Puis-je devenir bêta testeur ?

Non, nous ne recrutons pas de nouveau bêta testeurs.

### Le ModPack posséde t'il un Texture Pack par défaut ?

Oui, le ModPack posséde un Texture Pack crée par moi-même mais il n'est pas activer par defaut sur le client.

### Est-il possible de télécharger séparément le Texture Pack ?

Actuellement non mais surement dans un furtur proche.

### Les versions Alpha sont-elles encore supportés ?

Non, désormait elles n'obtiendront plus aucunes mise à jour.
